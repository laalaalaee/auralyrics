# Contributing to Auralyrics

Thanks for helping. Bug reports, ideas and pull requests are welcome.

Auralyrics is source-available under the [PolyForm Noncommercial License 1.0.0](LICENSE). Please read how contributions are licensed below before you open a pull request.

## Before you start

- For anything bigger than a small fix, open an issue first so we can agree on the direction.
- Run `npm install` then `npm test`. Tests must pass.
- Keep changes focused. One fix or feature per pull request.
- Commit messages: short and plain, saying what changed.

## Sign your commits

Add a sign-off line to every commit:

```
git commit -s -m "Fix glow flicker on display change"
```

This adds `Signed-off-by: Your Name <you@example.com>` and means you agree to the terms above. Pull requests without a sign-off will be asked to add one.

## Reporting security problems

Please do not open a public issue for a security problem. Email support@cloudfall.in instead.
